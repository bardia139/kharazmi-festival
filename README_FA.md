# سامانه جشنواره نوجوان خوارزمی

نسخه اولیه قابل استقرار با **GitHub Pages + Supabase**، رابط فارسی و راست‌چین.

## امکانات پیاده‌سازی‌شده
- فرم ثبت‌نام دانش‌آموز: نام و نام خانوادگی، موبایل والد، پایه، شماره کلاس و رشته
- نمایش رشته‌های فعال و ثبت‌نام از طریق RPC امن
- جلوگیری از ثبت‌نام تکراری همان دانش‌آموز در همان رشته (نام + شماره والد)
- کنترل ظرفیت و باز/بسته بودن رشته در سمت دیتابیس
- ورود مدیر با Supabase Auth
- داشبورد آمار و نمودار ثبت‌نام رشته‌ها
- افزودن، ویرایش، حذف، باز و بسته کردن رشته‌ها و تعیین ظرفیت
- جست‌وجوی دانش‌آموزان، فیلتر رشته، تماس مستقیم
- تغییر رشته یا حذف ثبت‌نام توسط مدیر
- خروجی Excel، چاپ فهرست و فایل پشتیبان JSON
- تغییر رمز مدیر

## ۱) راه‌اندازی Supabase
1. در https://supabase.com یک پروژه بسازید.
2. از بخش **SQL Editor** فایل `supabase/schema.sql` را کامل اجرا کنید.
3. از **Project Settings → API** این دو مقدار را بردارید:
   - Project URL
   - anon / publishable key (کلید عمومی؛ نه service_role)
4. در **Authentication → Users** یک کاربر بسازید:
   - Email: `topchi1405@qrypty.com`
   - رمز عبور قوی و محرمانه‌ای که خودتان انتخاب می‌کنید.
   اگر تأیید ایمیل فعال است، ایمیل را تأیید کنید یا تنظیمات تأیید را مطابق سیاست خود انجام دهید.
5. بعد از ساخت کاربر، در SQL Editor دستور زیر را اجرا کنید تا فقط همین حساب مدیر شود:

```sql
insert into public.admins(user_id)
select id from auth.users
where lower(email) = lower('topchi1405@qrypty.com')
on conflict do nothing;
```

6. در Authentication → URL Configuration، آدرس سایت GitHub Pages را به **Site URL** و **Redirect URLs** اضافه کنید. (پس از انتشار، URL دقیق سایت را وارد کنید.)

## ۲) راه‌اندازی GitHub
1. یک repository جدید و ترجیحاً Private یا Public به نام `kharazmi-festival` بسازید.
2. فایل‌های این پروژه را در ریشه repository بارگذاری کنید.
3. در GitHub بروید به **Settings → Secrets and variables → Actions → New repository secret** و این دو Secret را اضافه کنید:
   - `VITE_SUPABASE_URL` = آدرس Project URL
   - `VITE_SUPABASE_ANON_KEY` = کلید عمومی anon/publishable
4. در **Settings → Pages**، بخش Build and deployment را روی **GitHub Actions** بگذارید.
5. شاخه `main` را push کنید؛ workflow داخل `.github/workflows/deploy.yml` سایت را build و منتشر می‌کند.
6. پس از پایان workflow، لینک سایت در Settings → Pages نمایش داده می‌شود.

## ۳) اجرای محلی (اختیاری)
Node.js 20 یا جدیدتر لازم است.

```bash
npm install
cp .env.example .env.local
```

مقادیر Supabase را در `.env.local` قرار دهید و سپس:

```bash
npm run dev
```

برای تست build:

```bash
npm run build
```

## نکات امنیتی مهم
- هرگز کلید `service_role` یا رمز مدیر را در کد، GitHub، فایل `.env` عمومی یا پیام ارسال نکنید.
- کلید anon/publishable برای مرورگر است و با RLS و RPC محدود شده است.
- ثبت‌نام فقط از RPC دیتابیس انجام می‌شود؛ درج مستقیم برای کاربران ناشناس مجاز نیست.
- مدیر باید در جدول `public.admins` ثبت شده باشد؛ صرف ساختن حساب Auth دسترسی مدیریت نمی‌دهد.
- معیار جلوگیری از تکرار در این نسخه ترکیب «نام و نام خانوادگی نرمال‌شده + شماره موبایل والد + رشته» است. اگر شناسه دانش‌آموزی دارید، بهتر است برای جلوگیری دقیق‌تر از تکرار از آن استفاده شود.
- پشتیبان JSON که از پنل دانلود می‌شود شامل اطلاعات شخصی است؛ آن را در فضای امن نگهداری کنید.
- برای استفاده رسمی با اطلاعات کودکان، دسترسی به اطلاعات را محدود کنید، رضایت والدین و سیاست نگهداری/حذف اطلاعات را مشخص کنید و نسخه پشتیبان را رمزگذاری‌شده نگهدارید.
